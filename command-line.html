COMMAND LINE

Full command reference for RynthCore, RynthAi, and companion plugins.

Commands are typed into the in-game chat box. The /ra prefix is consumed by RynthAi before AC sees the line.

/ra — RynthAi

Bot Control

/ra power <0-100|auto> Set both melee and missile attack power (0–100). auto restores full power. Bare /ra power prints the current value.
/ra forcebuff Force-recast all buffs immediately, regardless of timer state.
/ra cancelforcebuff Cancel an in-progress force-rebuff sequence.
/ra clearbusy Force-clear all busy state — engine busy count, plugin busy count, combat busy, and buff counters. Use when the bot is stuck.
/ra panic Full AC reset: cancel attack, switch to peace mode, stop all motion, clear every busy count. Emergency stop.
/ra combat Dump a full snapshot of the combat state machine to chat — current state, target, busy flags, timers.

Diagnostics

/ra busyinfo Dump busy counts, current corpse/loot state, and give queue contents.
/ra cache Object cache summary — creature count, inventory item count, last update timestamps.
/ra cache2 Raw object cache stats plus a direct inventory snapshot from the AC object graph.
/ra attackable Check whether the current target qualifies as attackable under the bot's monster rules.
/ra wielded Show currently wielded items via the inventory cache.
/ra scan Show all nearby monsters with their LOS status and distance.
/ra dumpprops Dump player int, bool, and string properties to the log.
/ra dumpinv Dump all inventory items with GUIDs, names, and object classes.

Buffing

/ra forcebuff Force a full rebuff immediately — same as the Bot Control command.
/ra cancelforcebuff Cancel an in-progress rebuff.
/ra buffs Show active buff timers — spell name, tier, time remaining.
/ra buffs item Show item-spell buff debug output — which item buffs are tracked and their expiry.
/ra buffs tiers Show per-buff tier resolution debug — how each spell's tier was selected from the spellbook.
/ra bufftest Toggle the enchant-registry snapshot diagnostic — logs each registry read to the RynthCore log.

Casting

/ra cast <spellId> Cast a spell by numeric ID on the current target. Useful for testing specific spell IDs.

Navigation

/ra navdebug Show nav coordinate, current route waypoint, drift distance, and heading error.
/ra addnavpt Append a waypoint at the current position to the loaded .nav file and auto-save it.
/ra dunnav <NS> <EW> Run an A* pathfind to a dungeon coordinate without needing a pre-baked nav file. Prints path legs to chat.
/ra dunnav-patrol Start a circular hunt patrol through the entire current dungeon, visiting every reachable cell.

Geometry & Raycasting

/ra raycast Print raycasting system initialization status — whether the BSP hook is installed and hot.
/ra lostest LOS test to the current target using the default weapon type.
/ra lostest <mode> LOS test with an explicit mode: linear, bow, crossbow, atlatl, or magic. Each uses the appropriate arc/cone model.
/ra landtest Query terrain heightmap for the current landblock and print a grid of sample heights.
/ra rayland Fire landscape raycasts — one downward and one in each of 4 cardinal directions, 300 m each — and print hit distances.
/ra buildinfo Print geometry volume counts and list any buildings within range of the player.

Loot

/ra lootparse Inspect the currently loaded loot profile — rule count, file path, parse errors.
/ra lootparse <path> Parse and inspect a specific .utl loot profile without loading it as active.
/ra lootcheckinv Test the active loot profile against every item in the inventory cache and print each result.
/ra lootcheckinv <path> Same test using a specified profile path instead of the active one.
/ra lootcheck Classify the currently selected item against the active loot profile and print Keep/Leave/Sell.
/ra lootcheck on|off Toggle auto-classify mode — when on, each item you select is immediately classified and the result is shown in chat.

Corpses

/ra corpseinfo Show corpse range, how many corpses are tracked, and the open/loot diagnostic state.
/ra corpsecheck Explain step-by-step whether the selected corpse would be looted — range, ownership, completed set, loot profile.
/ra corpseopen Force the nearest eligible corpse through the open flow immediately, bypassing the timer.

Fellowship

/ra fellow Fellowship diagnostics: member list, leader, open/locked status, XP-share state. Alias: /ra fellowship.
/ra fellowinfo Fellowship tracker state — how many members are tracked, last update tick, any stale entries.

Give Items

Transfer items to another player. All variants accept an optional [count] before the item name. The item and player matching matrix:

One-shot give (single matching stack)
/ra give [count] <item> to <player> Exact item name, exact player name
/ra givep [count] <item> to <player> Partial item name, exact player name
/ra givexp [count] <item> to <player> Exact item name, partial player name
/ra givepp [count] <item> to <player> Partial item name, partial player name
/ra giver [count] <regex> to <player> Regex item match, exact player name
All-match give (every matching stack, throttled queue) — append stop to cancel
/ra givea <item> to <player> Exact item name, exact player name — transfers all matching stacks
/ra giveap <item> to <player> Partial item name, exact player name
/ra giveaxp <item> to <player> Exact item name, partial player name
/ra giveapp <item> to <player> Partial item name, partial player name
/ra givear <regex> to <player> Regex item match, exact player name
Loot-profile give (transfer all "Keep" items matching a .utl profile)
/ra ig <profile> to <player> Give all "Keep" items from the named loot profile, exact player name
/ra igp <profile> to <player> Same, partial player name match

Use Items

Use an item on yourself or on a second target. Scope selects whether to search inventory, the landscape, or both. Matching is exact or partial.

/ra use <name> [on <name2>] Exact name — inventory + landscape. Optional on <name2> uses item on a second object.
/ra usei <name> Exact name — inventory only
/ra usel <name> Exact name — landscape only
/ra usep <name> Partial name — inventory + landscape
/ra useip  /  /ra usepi Partial name — inventory only
/ra uselp  /  /ra usepl Partial name — landscape only

Select Objects

Same scope/matching matrix as Use, but selects the object rather than using it. Useful for targeting specific landscape objects.

/ra select <name> Exact name — inventory + landscape
/ra selecti <name> Exact name — inventory only
/ra selectl <name> Exact name — landscape only
/ra selectp <name> Partial name — inventory + landscape
/ra selectip <name> Partial name — inventory only
/ra selectlp <name> Partial name — landscape only

Jump

/ra jump[swzxc] [heading] [holdtime] Jump with optional direction keys and facing. Letter suffixes select keys held during the jump: s = run, w = forward, x = back, z = strafe left, c = strafe right. heading is 0–360 degrees. holdtime is milliseconds.
Example: /ra jumpsw 180 200 — hold run+forward, face south, for 200 ms.

Settings Profiles

/ra settings savechar <name> Save the current settings to a named per-character profile on disk.
/ra settings loadchar <name> Load a named per-character settings profile and apply it immediately.

Meta / Variables

/ra mexec <expression> Evaluate a meta expression inline and print the result. See the Expressions page for syntax.
/ra listvars List all session variables (cleared on logout).
/ra listpvars List all persistent variables (survive logout, saved to disk).
/ra listgvars List all global variables (shared across characters on the same account).

Misc

/ra mapdump Dump all landscape objects in the current landblock to the RynthCore log (GUIDs, names, positions).
/ra help Print the command list to chat.
/mt — Mag-Tools Compatibility

RynthAi accepts /mt commands as an alias layer. If you have meta files or macros written for Mag-Tools, most will work without changes.

Options

/mt opt list List all option names and their current values.
/mt opt get <option> Get the current value of one option.
/mt opt set <option> <value> Set an option by name.
/mt opt remember <option> Stash the current value of an option (for later restore).
/mt opt restore <option> Restore a previously stashed option value.
Valid option names
enablecombat enablelooting enablenav enablebuffing enablemeta opendoors idlepeacemode idlebufftopoff summonpets combinesalvage attackdistance approachdistance navpriorityboost lootpriorityboost dooropenrange autofellowmanagement switchwandstodebuff lootonlyrarecorpses

Actions

/mt combatstate <mode> Change combat mode: peace, melee, missile, or magic.
/mt face <degrees> Turn the character to the given heading (0–360).
/mt cast <id|name> [on <target>] Cast by numeric ID or exact spell name. Optional on <target> names the target.
/mt castp <partial> [on <target>] Cast by partial spell name.
/mt use <name> Use item — exact name, inventory + landscape.
/mt usep <name> Use item — partial name, inventory + landscape.
/mt usei <name> Use item — exact name, inventory only.
/mt useip <name> Use item — partial name, inventory only.
/mt usel <name> Use item — exact name, landscape only.
/mt uselp <name> Use item — partial name, landscape only.
/mt select <name> Select object — exact name, inventory + landscape.
/mt selectp <name> Select object — partial name, inventory + landscape.
/mt give <item> to <target> Give item — exact item name, exact player name.
/mt givep <item> to <target> Give item — partial item name, exact player name.
/mt loot <name> Loot item from open corpse — exact name.
/mt lootp <name> Loot item from open corpse — partial name.
/mt drop <name> Drop item to ground — exact name.
/mt dropp <name> Drop item to ground — partial name.
/mt equip <name> Equip item from pack — exact name.
/mt equipp <name> Equip item from pack — partial name.
/mt dequip <name> Unequip item to pack — exact name.
/mt dequipp <name> Unequip item to pack — partial name.
/mt fellow <action> Fellowship management: create, open, close, disband, quit, recruit.
/mt logoff  /  /mt logout  /  /mt quit  /  /mt exit Disconnect the current character from the server.
/ub — UtilityBelt Compatibility

Only the jump command is currently implemented under the /ub prefix. All jump syntax is identical to /ra jump.

/ub jump[swzxc] [heading] [holdtime] Identical to /ra jump. Suffixes: s = run, w = forward, x = back, z = strafe left, c = strafe right.
Host & Plugin Commands

/rc — RynthCore Host

Engine-level commands handled before any plugin or AC sees the line — they work even when the overlay bar is hidden.

/rc vitals Toggle the custom D3D9 HP / Stamina / Mana vital HUD. Setting persists to engine.json across relaunches. Alias: /rc hud.
/rc resetbar Reset the Avalonia overlay bar position to the top of the screen. Also accessible via the launcher's Reset Overlay Bar button. Alias: /rc barreset.

/rnav — RynthNav

Requires the RynthNav plugin and pre-baked navmesh tiles in C:\Games\RynthCore\NavData\. Type a coordinate and the plugin walks your character there automatically via DotRecast, avoiding buildings and obstacles.

/rnav goto <coord> Auto-walk to a map coordinate. Example: /rnav goto 2.7N, 18.9E. Stops on arrival.
/rnav stop Cancel active navigation and halt movement.
/rnav here Report the current landblock ID and navmesh tile status at the player's position.
/rnav load Reload the tile window around the player (useful after teleporting).
/rnav test Test whether the player is on the navmesh and print the result.
/rnav route <coord> Plan a portal-assisted route to the destination and display each leg — no movement started.
/rnav preview <coord> One-shot path preview for a nearby target — shows the planned path without committing to navigation.
/rnav portals on|off Toggle portal-assisted routing in multi-leg paths. Experimental; off by default.
/rnav help Print command usage to chat.

/rv — RynthVision

Requires the RynthVision plugin and a clean (no-Decal) client. Renders world overlays — radar, slope highlighting, water highlighting — directly into the D3D9 scene.

/rv radar Toggle the radar range ring overlay.
/rv slopes Toggle highlighting of unclimbable slope geometry.
/rv water Toggle highlighting of impassable water cells.
/rv watertypes Log terrain type indices at the player's current cell — diagnostic tool for water classification.
/rv debug Toggle player-pose diagnostic logging to the RynthCore log.
/rv Bare command — save current settings and log the current state of all overlays.

/juice — RynthJuice

Requires the RynthJuice plugin and a clean (no-Decal) client. Renders floating damage and heal numbers in-world above targets, with crit bursts and dungeon interior support.

/juice  /  /juice toggle Toggle floating damage numbers on/off.
/juice on  /  /juice off Explicitly enable or disable floating numbers.
/juice heals Toggle green heal numbers when you or a target is healed.
/juice playerdmg Toggle red damage numbers when you take a hit.
/juice scale <N> Set number size (0.3–4.0, default 1.0). Example: /juice scale 1.5.
/juice height <N> Set vertical offset above targets in meters (0–8, default ~1.8). Example: /juice height 2.0.
/juice test Spawn demo numbers and a kill burst at the player position to verify rendering is working.
/juice debug Toggle combat-log parsing output to the RynthCore log.
/juice help Print command usage to chat.
