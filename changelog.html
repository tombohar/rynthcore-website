CHANGELOG

Release history for RynthCore (engine + launcher) and RynthSuite (plugins).

Engine Plugin / RynthAi New Plugin Bug Fix

v0.21

Jun 7, 2026 RC release RS release
EnginePer-client log file (RynthCore.<pid>.log) — each running AC client writes its own session log. Makes multi-box diagnostics viable.
EngineOffline hang minidump — main-thread watchdog writes a .dmp on confirmed permanent wedge instead of relying on always-on procdump.
EngineOffline symbolicate tool (tools/symbolicate.py) — rewrites acclient.exe+0xRVA frames in a log to function names.
FixNon-modal floating panel resize/move — eliminates the game-freeze, cursor lag, and hard crash (LFH heap corruption) that occurred when dragging panels.
FixClose-time AV — swallows mouse/cursor input after WM_CLOSE so AC's freed combat-system singleton is never read during teardown.
EngineCustom D3D9 vital HUD — draws HP/Stamina/Mana bars directly via EndScene. Toggle with /rc vitals; drag/resize/persist.
EnginePattern-scan hardening — all 86 engine hook addresses now resolved by byte-signature scan at runtime. No hardcoded RVAs. Build-time self-check gate verifies every pattern against acclient.exe.
PluginAttack-cast delay: new AttackSpellIntervalMs setting (default 1500 ms) spaces war/void combat casts to avoid "too busy" drops.
PluginLoot speed: per-session regex cache (cap 2048) prevents recompile of 1600+ loot rules every match cycle; inter-corpse busy-leak watchdog cuts stall between corpses.
PluginMeta UI: enable/disable/duplicate state buttons wired; NUL-byte rendering artifact fixed.
NewRynthJuice — floating in-world damage/heal numbers with crit bursts. Works outdoors and in dungeons. Commands: /juice on|off|test|heals|playerdmg|scale|height|debug.

v0.20

Jun 3, 2026 RC release RS release
FixOff-thread AC mutation marshaling — P1 fix for the object-teardown corruption AV class (DBOCache::DestroyObj / List<ObjectRangeInfo>::remove). Achieved 2.5h+ clean soak.
PluginExplicit-target casting via FreeHandsAndCastSpell — combat spells no longer clobber the user's inventory selection. AC has one selection global; RynthAi now bypasses it entirely for magic.
PluginMode-flip spam throttled — repeated peace/combat state toggles dampened to prevent "too busy" cascade.
PluginActivity Arbiter steps 1–2: Nav↔Combat boundary is now authoritative; eliminates the "bot stands still" class of bugs caused by distributed BotAction state.

v0.19

May 25, 2026 RC release RS release
EngineNav3D renderer: double-buffered, triangle primitives, ring-with-height variant. Plugin API v61.
EngineEndScene pump upgraded to 60 Hz.
EngineNew Avalonia panels: Memory tab, MetaSourceEditor.
PluginSilent-no-show buff cooldown fix — resolves infinite "/god loop" hang when a buff was skipped silently.
PluginHazard cells, portal-NPC retry, LOS-aware patrol improvements.
NewRynthTracker — chat-driven activity tracker plugin.

v0.18

May 23, 2026 RC release RS release
NewRynthVision plugin — computer-vision integration panel.
EnginePlugin-gated panel registration — panels only activate if their backing plugin is loaded.
FixAvalonia click-through fix; position snapshot; AcActionTrace diagnostic.
PluginTerrainData shared lib added for dungeon geometry access.

v0.17

May 20, 2026 RC release RS v0.16.1
FixMain-thread object/attackable snapshot — eliminates cross-thread AV class from off-thread AC object reads.
EngineSEH trampoline for safer hook dispatch; click-through watchdog; Chat panel (new Avalonia panel).
FixSkill InqLevel enchant-registry null guard — prevents AV when the enchantment registry isn't populated yet.
FixNav freeze fix; Activity Arbiter step 2 authoritative.

v0.16

May 18, 2026 RC release RS release
EngineAppraisal-authoritative monster health — reads actual health from appraisal packets instead of estimating from quality data.
EngineChat command dispatch improvements; plugin API surface expanded.
EngineIn-AC ImGui shell re-enabled (alongside Avalonia panels).
PluginOffensive cast ACE fix — judgment-by-negation logic; "too busy" no longer counted as a miss.
PluginPermanent enchant (bane/Impen) support; 30s buff re-sync after death; wand classification fix.
PluginCastGateWatchdog — detects and breaks stuck casting states.
NewRynthChat plugin — chat buffer, classifier, and plugin exports.

v0.15

May 17, 2026 RC release RS release
EngineImGui shell force-disabled — Avalonia panels are the primary in-game UI. D3D9/ImGui still initialises for overlay positioning but renders nothing.
FixRaycast auto-resolves the AC dat folder from the injected acclient.exe's own path. Previously hardcoded, so raycasting never initialised for non-dev installs.
PluginCombat, buff, loot, meta, and legacy UI updates across the board.

v0.14

May 16, 2026 RC release RS release
EngineCObjectMaint seed — on login, existing world objects are replayed into the plugin's object cache so mobs already in range are detected immediately.
EngineObjectIsAttackable plugin API added.
FixLogin-mob detection rescue — bot now recognises mobs that were already in range at login instead of ignoring them.
FixBoostNav combat-starve fix — navigation priority boost no longer unconditionally returns, which was starving the combat loop.

v0.12

May 7, 2026 RC release
EngineOpt-in plugin discovery — the engine no longer auto-scans any folder. Plugins are registered explicitly via the launcher's Plugins tab and persisted in engine.json.
FixMulti-client DAT lock conflict fix — CLBlockAllocator::OpenDataFile patched to use shared-access flags.
EngineInstaller and documentation overhaul; second AC client install guidance added.

v0.11

May 7, 2026 RC release RS release
EngineLive object seed from CObjectMaint on engine init — world objects visible before injection are available immediately.
PluginSalvage robustness improvements; combat refactor; buff diagnostics commands.

v0.10

May 6, 2026 RC release
FixEliminated NativeAOT reverse-P/Invoke crash class — callbacks from native AC into managed code no longer risk a fail-fast on certain call patterns.
EnginePoll-driven auto-login — character selection and world entry now work without requiring user interaction after each inject.

v0.9

May 5, 2026 RC release RS release
EngineFull Avalonia panel suite — Radar, Meta, Items, Monsters, Nav, and Settings panels all ported. Replaces the legacy ImGui-only UI.
EngineEngine hot-reload — swap the engine DLL without restarting AC or the launcher. RynthCore.Loader thin-shim handles the bootstrap.
EngineLive panel resize — content reflows while dragging the grip, not just on mouse release.
EnginePanelStateStore — floating panel positions and open/closed state persist across sessions.
FixLogout crash — ChatHooks.TickHide was calling UIElement::SetVisible on a freed widget pointer during the world→char-select transition. Resolved by gating on login state.
FixWand detection fallback — name-based check (Orb/Staff/Wand/Scepter/Baton/Crozier) prevents "bot buffs with sword out" when TypeFlags packet hasn't arrived yet.
PluginAvalonia bridge, dungeon pathfinder, creature data system.

v0.8

Apr 26, 2026 RC release RS release
FixLogout crash — ChatHooks.TickHide was calling UIElement::SetVisible every frame on a freed gmMainChatUI pointer. AC frees that widget on world-exit; the next frame walked a freed vtable and AVed inside IsVisible+0x2B.
EngineOnLogout plugin lifecycle (API v57) — new RynthPluginOnLogout export; engine hooks CPlayerSystem::ExecuteLogOff (post-confirm, not pre-prompt).
FixTruly buffed skill — CACQualities::InqSkill(raw=0) replaces the bare level read. Spell tiers now scale correctly with high-buffed skills (e.g. Creature Enchantment).
PluginSeparate buff thresholds (BuffMinSkillLevelTier1..8); tier-upgrade-on-the-fly; /ra buffs tiers diagnostic.
FixVoid Magic — FindBestRingSpell no longer returns War-only lore rings for Void casters; Nether Ring / Corrosion Ring now resolve correctly.
PluginLooting overhaul — VTankLootEvaluator replaces VTankLootParser; SalvageManager respects per-material workmanship bands.
FixAuto-login one-shot latch — manual logout no longer instantly re-fires auto-login.

v0.7

Apr 25, 2026 RC release RS release
Engineimgui.ini pinned to a stable absolute path — window positions and dock layout persist across hot-reloads and AC restarts.
EngineNew SetPowerbarSuppressed plugin API (SDK v56).
PluginMana stone overhaul — drain-first priority, worn-gear refill by percentage, stone blacklist on timeout or "already full" chat.
PluginUST detection is type-based (AcObjectClass.Ust), universal across servers and item variants.
PluginBuff manager: vital-cast holds the BotAction lock; login refresh gate blocks casts until live memory is available.
PluginMeta UI: multi-action rules expand inline; right-click opens a 720×380 multi-line expression editor that auto-saves.
PluginDashboard theming — muted slate-blue palette replacing vivid sky-blue.
