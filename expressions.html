EXPRESSION ENGINE

Full reference for the RynthAi expression language used in meta conditions, chat actions, and loot rules. Expressions call functions and compose them with operators — there are no bare variable names in brackets.

Syntax

Every expression is a function call of the form funcname[arg1, arg2]. Function names are case-insensitive. Functions that take no arguments still use empty brackets: getcombatstate[]. The shorthand $name is exactly equivalent to getvar[name].

Function call — no arguments

getcombatstate[]

Returns the current combat mode string: "Peace", "Melee", "Missile", or "Magic".

Function call — with argument

getcharvital_current[1]

Returns the current Health value (vital ID 1).

Composed expression — condition

getcharvital_current[1] * 100 / getcharvital_buffedmax[1] < 40

True when health percentage is below 40%.

Variable shorthand

$kills  → equivalent to  getvar[kills]

Not bracket variables

This engine does not use a [VariableName] style. Every value comes from a function call like getcharburden[0]. If you are migrating from older uTank2 documentation, all your bare [Variable] references need to be rewritten as function calls.

Operators

Operators work between any two expression values. Standard operator precedence applies — use parentheses to be explicit.

Comparison

== != < <= > >=

Return true/false. Works on numbers and strings.

Logical

&& || !

AND, OR, NOT. Short-circuit evaluation applies.

Arithmetic

+ - * / %

Standard math. % is modulo.

Examples

getcharburden[0] > 75 && getfreeitemslots[] < 10
!(getequippedweapontype[] == Wand)
getpvar[kills] % 100 == 0

Variable Storage

Three independent scopes, each with the same six operations. Use session vars for temporary scratch, pvar for per-character progress that survives logout, and gvar for values shared across all characters.

Session In-memory only — lost on logout or reload
setvar[name, value]Store a value.
getvar[name]Read a value (or shorthand $name).
testvar[name]True if the variable exists.
touchvar[name]Create with empty value if not set; no-op otherwise.
clearvar[name]Delete a single variable.
clearallvars[]Delete all session variables.
Persistent (pvar) Disk-backed, per-character
setpvar[name, value]Store a value to disk.
getpvar[name]Read a persisted value.
testpvar[name]True if the variable exists on disk.
touchpvar[name]Create with empty value if not present.
clearpvar[name]Delete from disk.
clearallpvars[]Delete all pvars for this character.
Global (gvar) Disk-backed, shared across all characters
setgvar[name, value]Store a shared value.
getgvar[name]Read a shared value.
testgvar[name]True if the variable exists.
touchgvar[name]Create with empty value if absent.
cleargvar[name]Delete a global variable.
clearallgvars[]Delete all global variables.

Vitals

Vital IDs: 1 = Health, 2 = Stamina, 3 = Mana.

getcharvital_current[vitalId]Current value in absolute points.
getcharvital_buffedmax[vitalId]Buffed maximum (what the bar is full at).
getcharvital_base[vitalId]Unbuffed base maximum.

Examples

getcharvital_current[1] * 100 / getcharvital_buffedmax[1] < 40

True when health percentage is below 40%.

getcharvital_current[3] < 500

True when mana points are below 500.

Common Patterns

Real meta scripts composed from the functions above. These are the patterns that come up most frequently in combat, buffing, and navigation metas.

Health below 40% — go to heal state
getcharvital_current[1] * 100 / getcharvital_buffedmax[1] < 40

Current HP as a percentage of buffed max. Works for Stamina (2) and Mana (3) the same way.

Save kill count persistently across sessions
setpvar[kills, getpvar[kills] + 1]

Reads the current count, adds one, and writes it back to disk. Survives logout. Touch the var first on meta start to seed it at 0 if absent.

Buff state when any key spell is expiring
getspellexpiration[1234] < 30 || getspellexpiration[5678] < 30

True when either spell has less than 30 seconds left. Chain as many spells as needed with ||.

Is there a monster in range?
wobjectisvalid[wobjectfindnearestmonster[]]

The find returns a handle; wobjectisvalid returns true only if a real object was found.

Inventory full — trigger town run
getfreeitemslots[] < 5 || getcharburden[0] > 90

True when fewer than 5 free item slots, or burden exceeds 90%. Either condition triggers the action.

Branch on equipped weapon type
iif[getequippedweapontype[] == Wand, doMagicAction[], doMeleeAction[]]

iif is lazy — only the matched branch evaluates.

Save an XP checkpoint
setpvar[xp_checkpoint, getcharquadprop[273]]

STypeQuad 273 is total XP. Store it on state entry, then compare later with getcharquadprop[273] - getpvar[xp_checkpoint] for XP earned this session.

Print player position to chat
echo[coordinatetostring[getplayercoordinates[]], 0]

Formats the player's coordinates as a readable string and prints it locally in white chat.
