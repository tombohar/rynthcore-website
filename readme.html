RynthCore

RynthCore is a modern .NET 10 modding stack for Asheron's Call. It consists of a three-tier injection architecture (Loader → Engine → Plugins), an Avalonia desktop launcher, and the RynthSuite plugin ecosystem (RynthAi, RynthNav, RynthJuice, RynthVision, RynthTracker, RynthChat).

Architecture

The three-tier injection model keeps the Engine hot-swappable without restarting AC:

acclient.exe
  └─ RynthCore.Loader.dll     ← injection target. Exports RynthCoreInit.
       └─ RynthCore.Engine.dll ← ~26 MB NativeAOT x86 PE. All hooks + UI.
            └─ Plugins\*.dll   ← shadow-copied, hot-reloadable plugin DLLs.

The Loader exists so the Engine can be freed and hot-swapped without restarting AC.

Solution layout

  • src/RynthCore.Loader — x86 NativeAOT DLL, injection target. Owns RynthCoreInit, loads and hot-reloads the Engine.
  • src/RynthCore.Engine — x86 NativeAOT DLL, the runtime injected into acclient.exe. Pattern-scanned hooks, D3D9+ImGui+Avalonia overlays, plugin manager, crash/hang watchdog, logging.
  • src/RynthCore.Injector — x86 console tool. Win32 LoadLibrary + CreateRemoteThread injector with a suspended-launch/early-inject path.
  • src/RynthCore.App.Avalonia — the desktop launcher (Avalonia 11.2.3, Fluent theme). Server/account profiles, plugin management, multi-client session management, auto-inject watcher.
  • src/RynthCore.App — shared service classes compiled into both the Engine and the Avalonia launcher via <Compile Include>. Not a standalone build target.
  • src/RynthCore.PluginSdk — public host API surface for plugins. ~100 native function pointers, API version-gated.
  • src/RynthCore.PluginCore — RynthPluginBase + lifecycle helpers (Initialize, Shutdown, OnTick, OnLoginComplete, OnChatBarEnter, OnDeleteObject, OnEnchantment*, etc.)

Prerequisites

  • Windows 10 or 11
  • .NET 10 SDK (x86)
  • Visual Studio 2022 Build Tools with .NET desktop and C++ desktop workloads (required by NativeAOT ILC linker)
  • Asheron's Call client installed

Build

From the repository root:

$env:DOTNET_CLI_HOME = "$PWD\.dotnet-home"
dotnet build .\RynthCore.sln -c Release

For NativeAOT projects, use dotnet publish (not dotnet build):

dotnet publish .\src\RynthCore.Loader\RynthCore.Loader.csproj -c Release
dotnet publish .\src\RynthCore.Engine\RynthCore.Engine.csproj -c Release
dotnet publish .\src\RynthCore.App.Avalonia\RynthCore.App.Avalonia.csproj -c Release

Deploy

.\scripts\Deploy-RynthCore.ps1

Deploys to C:\Games\RynthCore\ — launcher at root, engine+loader+plugins under Runtime\.

Plugin loading (opt-in)

The engine does not auto-scan any folder. Plugins are registered via the launcher's Plugins tab → Add Plugin DLL, stored in %APPDATA%\RynthCore\engine.json. Hot-reload is available via the RL button on the overlay.

Logging

  • C:\Games\RynthCore\Logs\RynthCore.log — shared launcher/orchestration log
  • C:\Games\RynthCore\Logs\RynthCore.<pid>.log — per-client session log (one per running AC process)
  • Offline symbolication: tools\symbolicate.ps1 — rewrites acclient.exe+RVA frames to function names
